# testimonialPost(testimonial) — the repeatable ritual

Turn any testimonial Greg forwards into a story carousel. Three inputs, one
paste into Claude Design, same staging pipeline as every other carousel.

**Inputs:** ① the testimonial text (verbatim) ② Greg's answers from the
"testimonials" share-link question set (situation / worry / turning point /
result / permission) ③ permission level (named or anonymous).

**Rules:** the client's words go on slides VERBATIM or not at all — never
paraphrase a quote and present it as theirs. Name only if permission says so;
otherwise "a seller in <town>" / "a couple from <province>". No DM keywords;
CTA = call 902-888-9232. No invented numbers.
