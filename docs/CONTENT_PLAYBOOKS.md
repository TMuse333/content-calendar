# Content Strategy Playbooks

Strategic frameworks for analyzing and creating content. Use these three lenses to ensure every piece of content is intentional and effective.

---

## Three-Level Strategic Analysis

Analyze any piece of content through THREE strategic lenses. Focus on WHY choices were made, not WHAT is shown.

---

## Lens 1: Information Theory

**Key Question:** "What can't be said in words that the visual shows?"

How does information flow between channels?

### Components

| Component | Description |
|-----------|-------------|
| **SIGNAL** | What is the ONE core idea being communicated? |
| **CHANNELS** | Audio, visual, text, motion - which are used? |
| **MODE** | How do channels work together? |

### Channel Modes

- **Redundant** = visual repeats audio (reinforcement)
- **Complementary** = visual adds info not in audio (expansion)
- **Primary** = one channel carries meaning, other supports

### Channel Switching Triggers

When and why to switch channels:
- "Audio overloaded → switch to visual"
- "Abstract concept → needs visualization"
- "Emotional moment → strip to talking head"

---

## Lens 2: Human Nature

**Key Question:** "What does the viewer FEEL at each moment, and why?"

What psychological mechanisms are being engaged?

### Primary Desires

Wants that can be activated:
- Status
- Belonging
- Security
- Mastery
- Autonomy
- Novelty

### Primary Fears

Fears that can be activated:
- Missing out (FOMO)
- Falling behind
- Looking foolish
- Being judged
- Losing control

### Identity Play

Phrases that invoke identity:
- "You're the type of person who..."
- "People like you..."
- "If you're serious about..."

### Emotional Arc

Standard progression:
```
Curiosity → Understanding → Desire → Urgency → Action
```

---

## Lens 3: Literary Devices

**Key Question:** "What story is being told, and how?"

What storytelling techniques are employed?

### Narrative Structures

- Problem → Solution
- Before → After
- Question → Answer
- Journey → Transformation
- Setup → Conflict → Resolution

### Devices

| Device | Function |
|--------|----------|
| **Metaphor** | Abstract made concrete |
| **Contrast** | Before/after, us/them |
| **Rule of Three** | Lists, examples (memorable pattern) |
| **Open Loop** | Question raised, answered later (retention) |
| **Social Proof** | Others' experiences (trust) |
| **Future Pacing** | Vivid outcome description (desire) |
| **Scarcity** | Limited availability (urgency) |
| **Authority** | Credentials, experience (trust) |

---

## Output Format

For each significant moment/section, document:

```
1. INFORMATION THEORY
   Signal: [what concept]
   Mode: [redundant/complementary/primary]
   Channel logic: [why this channel]

2. HUMAN NATURE
   Trigger: [desire/fear activated]
   Purpose: [cognitive work being done]
   Emotion: [feeling created]

3. LITERARY DEVICE
   Device: [technique used]
   Function: [role in narrative]

4. TRANSFERABLE INSIGHT
   [One-line principle applicable to ANY content]
```

## The Ultimate Question

> "What subject-agnostic principle is being applied here that works for ANY content?"

## Format-Specific Recommendations

### This or That / Comparison Content
- **Primary Device:** Contrast
- **Human Nature:** Decision simplification, reducing cognitive load
- **Information Theory:** Complementary mode (visual comparison adds what text can't)

### Myth vs Fact
- **Primary Device:** Contrast + Authority
- **Human Nature:** Fear of looking foolish, desire for mastery
- **Information Theory:** Redundant mode (text reinforces visual)

### Process Timeline
- **Primary Device:** Journey structure
- **Human Nature:** Desire for control/mastery, fear of unknown
- **Information Theory:** Primary visual (timeline graphic carries meaning)

### Q&A / Client Questions
- **Primary Device:** Open Loop (question hooks), Authority
- **Human Nature:** Curiosity, desire for insider knowledge
- **Information Theory:** Complementary (answer expands beyond question)

### Market Stats
- **Primary Device:** Authority, Social Proof (data as evidence)
- **Human Nature:** Fear of falling behind, desire for informed decisions
- **Information Theory:** Primary visual (charts/numbers carry meaning)

### Neighbourhood Guide
- **Primary Device:** Future Pacing, Social Proof
- **Human Nature:** Belonging, identity ("people who live here are...")
- **Information Theory:** Complementary (visuals show lifestyle text describes)

## Content Principles

### Core Beliefs

1. **Signal over noise** - Every element must serve the core message
2. **Emotion before logic** - Feel first, think second
3. **Specific beats generic** - Concrete details build credibility
4. **Tension creates attention** - Open loops, contrast, stakes

### Red Flags

- Multiple competing signals (confused message)
- All logic, no emotion (forgettable)
- Generic statements (unbelievable)
- No tension or stakes (boring)
